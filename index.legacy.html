InventoryOS

Operational Inventory Management System

A Mini ERP with full backend integration — real-time stock tracking, order management, supplier records, multi-category analytics, and role-based access control. Built across 9 production screens. Designed to eliminate manual stock sheets and reduce inventory discrepancy in multi-role warehouse environments.

Architecture
Frontend
React + Zustand + React Query + Recharts
Backend
Supabase · PostgreSQL · RLS · Auth
Deploy
Vercel · GitHub CI/CD · Realtime
Key Engineering Decisions
  • → Supabase RLS for row-level security per user role
  • → React Query for server state + optimistic updates
  • → Zustand for lightweight client state management
  • → PostgreSQL constraints + transactions prevent race conditions when multiple staff update the same SKU simultaneously
PostgreSQL Schema Snapshot
-- products
id          uuid primary key
sku         text unique not null
name        text not null
category_id uuid references categories(id)
unit_cost   numeric(10,2)
reorder_pt  integer default 10

-- inventory_movements
id          uuid primary key
product_id  uuid references products(id)
type        text check (type in ('in','out','adjustment'))
quantity    integer not null
user_id     uuid references auth.users(id)
created_at  timestamptz default now()

-- RLS policies
staff  → select only on products, movements
admin  → full access all tables

04 — Stack & Tools

Tools I use and why.

Each tool is chosen for a specific reason — not just familiarity.

Frontend
React
Primary

Component architecture for complex dashboard UIs. Ecosystem (Zustand, React Query, Recharts) covers every operational app need.

Vue.js
Secondary

Cleaner syntax for content-heavy internal applications. Vue's reactive architecture maps seamlessly to complex multi-step operational forms and CMS-style interfaces.

Tailwind CSS
Styling

Utility-first keeps design consistent across complex multi-screen dashboards without fighting a design system.

Recharts
Data Viz

Composable SVG charts with React. Customizable enough for production dashboards without heavy library overhead.

Backend & Database
Supabase
Core Backend

Postgres + Auth + Realtime + Storage in one platform. Row-Level Security replaces custom auth middleware. Built for operational systems.

PostgreSQL
Database

Relational integrity for inventory, order, and supplier data. Foreign keys, indexes, and views — not a document store afterthought.

Supabase Realtime
Live Data

WebSocket-based Postgres change listeners. Essential for live dashboards, stock alerts, and multi-user operational apps.

Supabase RLS
Security

Policies written in SQL enforce access at the database layer — not just the API layer. Role-based access that can't be bypassed.

Deployment & CI/CD
Vercel
Frontend Deploy

Preview deployments per PR, global edge CDN, zero-config for React/Vue. Build pipeline that takes 30 seconds.

GitHub
Version Control

Branch strategy, GitHub Actions for CI, automated deploys on merge. Every project version-controlled from day one.

Cloudflare
Edge / DNS

DNS management, edge caching, and DDoS protection. Static sites go through Cloudflare Pages for global distribution.
